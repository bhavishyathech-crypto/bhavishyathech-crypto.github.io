# Bhavishya Thech — Data Analyst Portfolio

## Files
- `index.html` — portfolio page
- `style.css` — responsive design
- `script.js` — mobile menu + scroll reveal
- `Bhavishya_Thech_Resume.pdf` — resume (included if available when package was generated)
- `profile.png` — add your final professional profile photo with this exact filename

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository, e.g. `bhavishyathech-portfolio`.
2. Upload all files from this folder to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save and wait for the Pages URL.

## Before publishing
- Replace/add `profile.png` with your professional photo.
- Add GitHub links for the additional projects if you want them clickable.
- Confirm the resume PDF is present as `Bhavishya_Thech_Resume.pdf`.
